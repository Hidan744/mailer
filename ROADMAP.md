# План запуска в боевую эксплуатацию

Зафиксировано по состоянию на 11.09.2026. Технически приложение готово (см. README) —
это план доведения до реальной боевой рассылки.

## Доработка чек-пойнта ротации (п.5 ТЗ)

По умолчанию было: кампания сама останавливается каждые 50–100 писем и просит оператора
вручную поправить текст. По запросу заказчика добавили автоматический режим: при создании
кампании можно заранее заготовить 2–5 вариантов темы/текста — тогда по достижении порога
кампания сама переключается на следующий вариант по кругу, **без остановки рассылки**.
Если ни одного доп. варианта не заполнено — работает старое поведение (пауза на правку).

  `mail.vinakovlab.online` — подключаться нужно по реальному хостнейму сервера
  (`server276.hosting.reg.ru`, узнаётся через `dig -x <IP почтового сервера>`).
- В приложении не было редактирования почтового ящика (только удалить/пересоздать) —
  добавили кнопку "Изменить" в Настройках.
- Письма, не ушедшие из-за временной ошибки, раньше не переотправлялись — добавили
  кнопку "Повторить ошибки" в кампании.
