# Что осталось до боевого запуска

Техническая часть готова и проверена реальной отправкой (SMTP/IMAP работают, письмо
доставлено, ответы и открытия отслеживаются). Осталось три группы задач: материалы от
заказчика, финальные проверки и сам запуск.

## 1. Нужны материалы и решения от заказчика

| Что | Зачем | Кто делает |
|---|---|---|
| Логотип компании (jpg) + реквизиты/контакты для подвала письма | Фирменный бланк — сейчас письма уходят без логотипа | Заказчик присылает файл и текст, исполнитель загружает в Настройки |
| Реальный список получателей (Excel: Компания/Должность/Фамилия И.О./Имя Отчество/Email) | Сейчас есть только тестовые адреса | Заказчик готовит файл по шаблону |
| Уточнение формата номера "0210/186" (что означает "0210") | Для точной настройки автонумерации | Не блокирует запуск — теперь можно задать номер вручную для любого получателя отдельно |

## 2. Финальные проверки перед боевым запуском

| Что | Статус |
|---|---|
| Реальная отправка через SMTP | Готово — доставлено на Yandex |
| Вёрстка письма в Gmail, Outlook | Не проверено (проверено только в Yandex) |
| Проверка на спам-оценку (mail-tester.com или аналог) | Не проверено |
| Тестовая рассылка с итоговыми данными (логотип + реальный текст + реальный список) | После получения материалов из п.1 |

## 3. Запуск

- **Первые 1–2 недели** — небольшими партиями, не сразу вся база (прогрев ящика, чтобы
  не попасть в спам как новый отправитель).
- **Дальше** — по расписанию 9:00–17:00, обед 12:00–13:00, раз в 5 минут — уже настроено
  и работает автоматически, вмешательство не требуется.

## 4. Необязательно, можно уже после запуска

- Автотесты кода (сборка шапки, окно отправки, чек-пойнт ротации).
- Регулярные бэкапы базы данных и мониторинг сервера.

---

**Итого для запуска в бой не хватает только**: логотипа/реквизитов, реального списка
получателей и двух проверок (вёрстка в других почтовиках + спам-оценка). Как только
заказчик присылает материалы — всё остальное делается за один день.
